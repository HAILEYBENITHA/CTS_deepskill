# Week 6 - CTS Deep Skill Training

## Overview

This repository contains the exercises completed during Week 6 of the Cognizant Deep Skill Program.

The exercises focus on **Git version control**, covering Git setup, configuration, `.gitignore`, branching & merging, conflict resolution, and pushing changes to remote repositories.

---

## Modules Covered

### Module 1 - Git
- Exercise 1 - Git Setup, Configuration & First Commit
- Exercise 2 - Git Ignore
- Exercise 3 - Branching and Merging
- Exercise 4 - Conflict Resolution
- Exercise 5 - Clean up and Push back to remote Git

---

## Technologies Used

- Git Bash
- GitLab / GitHub
- Notepad++ (as default Git editor)
- P4Merge (for visual diff and merge conflict resolution)
